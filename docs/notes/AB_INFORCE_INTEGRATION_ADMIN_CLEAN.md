# Интеграция AB Inforce: Описание сущностей и функционала админки (Версия для PDF)

В данном документе описаны основные сущности системы Antigravity PFP, их структура (названия переменных) и задачи, которые решаются в административной панели.

## 📋 Основные сущности

### 1. Финансовые продукты (PFP Products)
Используются для формирования инвестиционных портфелей и расчетов доходности.

**Переменные продукта:**
- `id` — Уникальный идентификатор.
- `name` — Название продукта.
- `product_type` — Код типа (PDS, IIS, ISZH и т.д.).
- `currency` — Валюта (RUB, USD).
- `min_term_months` / `max_term_months` — Минимальный/максимальный срок в месяцах.
- `min_amount` / `max_amount` — Минимальная/максимальная сумма.
- `yields` — Массив линий доходности.
    - `yield_percent` — Процент доходности.
    - `term_from_months` / `term_to_months` — Диапазон сроков.
    - `amount_from` / `amount_to` — Диапазон сумм.

### 2. Портфели (Portfolios)
Готовые стратегии распределения капитала.

**Переменные портфеля:**
- `id` — Уникальный идентификатор.
- `name` — Название стратегии.
- `currency` — Валюта.
- `riskProfiles` — Массив риск-профилей (CONSERVATIVE, BALANCED, AGGRESSIVE).
    - `potential_yield_percent` — Целевая доходность.
    - `instruments` — Состав портфеля (продукты и их доли).
        - `product_id` — ID продукта.
        - `share_percent` — Доля в процентах.
        - `bucket_type` — Тип сегмента (INITIAL_CAPITAL, TOP_UP).

### 3. Агенты (Agents)
Финансовые консультанты, работающие в системе.

**Переменные агента:**
- `id` / `uuid` — Идентификаторы.
- `first_name`, `last_name`, `middle_name` — ФИО.
- `email`, `phone` — Контактные данные.
- `telegram_bot` — Ссылка на персонального бота.
- `telegram_channel_id` — ID канала для рассылок.
- `is_active` — Статус активности.
- `specialization`, `experience_years` — Квалификация.

### 4. ИИ Ассистенты и Конструктор (AI & Constructor)
Настройка логики общения чат-ботов и базы знаний.

**Переменные ассистента (`AiAssistant`):**
- `name` — Название ассистента.
- `slug` — Технический код.
- `model` — Используемая LLM модель (например, gemini-1.5-flash).
- `context_template` — Системный промпт.

**Переменные конструктора (Шаблоны):**
- `command` — Название команды/стадии диалога.
- `classifier` — Критерии перехода на эту стадию.
- `response` — Текст ответа или инструкции для ИИ.
- `section` — Категория (CJM этап).

### 5. Страхование имущества (Home Owners)
Параметры страховых продуктов для домов и квартир.

**Переменные продукта страхования:**
- `name` — Название.
- `rate_constructive`, `rate_finish`, `rate_property`, `rate_civil` — Базовые ставки по рискам (конструктив, отделка, движимое имущество, ГО).

**Переменные тарифа (Коэффициенты):**
- `parameter_name` — Имя параметра (например, `wall_material`).
- `parameter_value` — Значение (например, `wood`).
- `coefficient` — Множитель для расчета премии.
- `coefficient_type` — Тип (множитель или фикс).

## 🛠 Функционал админки

В административной панели выполняются следующие ключевые действия:

1.  **Управление каталогом продуктов:**
    - Создание и редактирование банковских и инвестиционных продуктов.
    - Настройка сеток доходности в зависимости от срока и суммы.
2.  **Моделирование портфелей:**
    - Сборка портфелей из существующих продуктов.
    - Определение долей инструментов для разных профилей риска.
3.  **Администрирование агентов:**
    - Регистрация новых консультантов.
    - Мониторинг активности и прав доступа.
4.  **Конструктор сценариев ИИ:**
    - Редактирование шаблонов поведения ботов (Constructor Templates) без использования динамических контекстов.
5.  **Конфигурация страховки:**
    - Настройка тарифных справочников и поправочных коэффициентов.
    - Управление списком доступных страховых объектов.
6.  **Глобальные настройки системы:**
    - Обновление налоговых ставок (2-НДФЛ).
    - Настройка параметров государственного софинансирования ПДС.
    - Управление ключами API и лимитами нейросетей.
