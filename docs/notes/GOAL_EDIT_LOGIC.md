# Спецификация редактирования целей выпуска

Этот документ описывает, какие параметры можно изменять для каждого типа цели в финансовом плане. 
Все изменения отправляются через `POST /api/client/:id/recalculate`.

**Алгоритмы пересчёта** (что пересчитывается при изменении параметров, формулы) описаны в [RECALCULATE_ALGORITHMS.md](../RECALCULATE_ALGORITHMS.md).

---

## 🏗 Общая логика
Бэкенд поддерживает "умное" слияние: если вы отправляете только часть полей, остальные подтянутся из базы. 
При любом изменении запускается **Smart Allocation** (алгоритм "Бремя"), который перераспределяет свободный капитал клиента между целями.

Правило режима расчета:
- если по цели передан `monthly_replenishment > 0`, включается forward-режим (считаем достижимый результат от заданного пополнения);
- если `monthly_replenishment` не передан или равен `0`, работает классический режим от `target_amount` (подбор пополнения).
- тип цели (`goal_type_id`) и формат ответа API не меняются.

## 🎯 Параметры по типам целей

### 1. Госпенсия (PENSION, ID=1)
*Самая сложная цель, задействует государственные калькуляторы.*

| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Желаемая пенсия** | `target_amount` | Сумма, которую клиент хочет получать в месяц (в ценах сегодня). |
| **Инфляция** | `inflation_rate` | Годовой % инфляции для индексации желаемой суммы. |
| **ИПК** | `ipk_current` | Текущий пенсионный балл клиента (из справки СФР). |
| **Капитал в ОПС** | `ops_capital` | Накопительная пенсия. Сразу добавляется в "стартовый капитал" цели. |
| **Стартовый капитал** | `initial_capital` | Сколько денег клиент выделяет прямо сейчас из своих накоплений. |
| **Риск-профиль** | `risk_profile` | `CONSERVATIVE`, `BALANCED`, `AGGRESSIVE`. |
| **Доход клиента** | `avg_monthly_income`| *(Параметр клиента)* Влияет на прогноз будущих баллов ИПК. |

---

### 2. Пассивный доход (PASSIVE_INCOME, ID=2)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Желаемый доход** | `target_amount` или `desired_monthly_income` | Сумма ежемесячной "ренты" в текущих ценах. |
| **Инфляция** | `inflation_rate` | Годовой % инфляции для индексации желаемого дохода. |
| **Срок накопления** | `term_months` | Через сколько месяцев клиент хочет начать получать доход. |
| **Стартовый капитал** | `initial_capital` | Начальная сумма для инвестирования. |
| **Риск-профиль** | `risk_profile` | Влияет на ожидаемую доходность портфеля. |

---

### 3. Защита Жизни (LIFE, ID=5)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Страховая сумма** | `target_amount` | Целевой капитал в конце срока (выплата по дожитию). |
| **Срок программы** | `term_months` | Длительность контракта НСЖ (в месяцах). |


---

### 4. Крупная покупка (OTHER, ID=4)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Стоимость покупки** | `target_amount` | Текущая цена объекта (недвижимость, авто и т.д.). |
| **Срок до покупки** | `term_months` | Через сколько месяцев планируется сделка. |
| **Стартовый капитал** | `initial_capital` | Сумма, которая уже есть на эту покупку. |
| **Инфляция** | `inflation_rate` | На сколько объект дорожает в год. |
| **Риск-профиль** | `risk_profile` | Стратегия накопления (`CONSERVATIVE`, `BALANCED`, `AGGRESSIVE`). |

---

### 5. Инвестиции (INVESTMENT, ID=3)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Срок** | `term_months` | Длительность инвестирования. |
| **Стартовый капитал** | `initial_capital` | Начальная сумма. |
| **Риск-профиль** | `risk_profile` | Тип портфеля. |
| **Ежем. пополнение** | `monthly_replenishment` | Планируемый ежемесячный взнос в портфель. |

---

### 6. Финрезерв (FIN_RESERVE, ID=7)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Стартовый капитал** | `initial_capital` | Сумма, которая уже есть. |
| **Ежем. пополнение** | `monthly_replenishment`| Планируемый взнос в месяц. |
| **Срок накопления** | `term_months` | Срок формирования резерва (в месяцах). |

---

### 7. Ежемесячный процент (RENT, ID=8)
| Параметр в UI | Поле API | Описание |
| :--- | :--- | :--- |
| **Стартовый капитал** | `initial_capital` | Сумма, которую кладем на ренту (только этот параметр). |
| **Риск-профиль** | `risk_profile` | Влияет на процентную ставку рентного дохода. |

## 💡 Общие параметры клиента (Dashboard)
Эти поля можно передавать внутри объекта `client` в запросе на пересчет:

- **`total_liquid_capital`**: Общая сумма "свободных" денег клиента. Если ее увеличить, бэкенд автоматически добавит излишек в инвестиции или на покрытие дефицита по целям.
- **`avg_monthly_income`**: Влияет на право получения льгот (ПДС) и расчет пенсии.

## 🛠 Технический пример запроса (Recalculate)

```json
{
  "client": {
    "avg_monthly_income": 250000 
  },
  "goals": [
    {
      "goal_type_id": 1,
      "name": "Пенсия через 20 лет",
      "target_amount": 200000,
      "ops_capital": 450000,
      "initial_capital": 1000000
    }
  ]
}
```
