# API Documentation

Здесь лежит структура и документация по всем API методам. Каждая часть (domain) расписана в отдельном YAML файле.

## Структура файлов

| Файл | Описание |
|------|-----------|
| `openapi/pfpB2C.yaml` | (Библиотека схем B2C) Общие схемы и параметры для ЛК клиента (AuthResponse, CalculationRequest/Goal и т.д.). Эндпоинты описаны в `docs/api/b2c_lk.yaml`. |
| `openapi/pfp-api-v1.2.yaml` | (Текущий рабочий расчетный API) Общие схемы и пути для расчёта финансовых целей (Пенсия, Пассивный доход и т.д.), а также AI/CRM-часть. Используется и B2C, и ЛК Агента. |
| `docs/api/b2c_lk.yaml` | **(НОВЫЙ ЦЕЛЕВОЙ)** Единый API для фронтенда ЛК клиента. Объединяет в себе эндпоинты из B2C-слоя (`/my/...`) и использует схемы из `pfpB2C.yaml` и `pfp-api-v1.2.yaml`. |
| `docs/api/agent_lk.yaml` | **(НОВЫЙ ЦЕЛЕВОЙ)** API для Личного Кабинета Агента. Управление продуктами, портфелями и настройками планов, подхват B2C-планов, AI B2C-настройки. |
| `docs/api/aiB2c.yaml` | (Архив/Справка) Детальное описание методов для работы B2C AI: админка (управление контекстами и стейджами) и клиентская часть. |
