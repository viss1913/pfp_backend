# Классификатор B2C: этап выбора цели (копипаст в `constructor_commands.classifier`)

Вставь **целиком** в поле классификатора команды, на которой пользователь выбирает цель (например `/chooseTarget` или как у тебя назван этап).  
Ответ роутера — **одна строка, только ключ команды** из списка бота.

---

```
СЕЙЧАС ПОЛЬЗОВАТЕЛЬ НА ЭТАПЕ ВЫБОРА ЦЕЛИ. Ответь ОДНИМ ключом команды из списка.

ПРИОРИТЕТ (прочитай первым):
— /gosPension — ТОЛЬКО если пользователь явно говорит про пенсию: госпенсия, страховая пенсия, «достойная пенсия», пенсия, выход на пенсию, дополнительный доход К ПЕНСИИ, разрыв с госпенсией. Одного слова «посчитать», «давай посчитаем», «интересно сколько» БЕЗ темы пенсии — НЕДОСТАТОЧНО. НЕ выбирай /gosPension, если пенсия не названа.
— Если пользователь хочет «просто посчитать», «ну давай посчитаем», «сколько получу/накоплю», «сколько выйдет если вложу», «интересно вклад», «без цели», «не знаю на что копить», «просто узнать цифру» — и при этом НЕ говорит про пенсию — всегда /INVESTMENT.
— Если в истории бот упоминал пенсию, но в ЭТОМ сообщении пользователь явно уходит в «просто посчитай / без цели / сколько накоплю» без слова пенсия — /INVESTMENT, не /gosPension.

ДАЛЕЕ ПРАВИЛА МАРШРУТИЗАЦИИ:
— Полноценный финансовый план (несколько целей, весь план, «всё посчитай» в смысле комплексно) → /chooseTarget
— Только узнать, сколько получит/накопит при вложениях, калькулятор без жёсткой цели, «не знаю на что копить» → /INVESTMENT
— Цель «пассивный доход» → /passiveIncome
— Загородный дом или таунхаус → /home
— Квартира → /apartment
— Свой бизнес, переезд в другой город, автомобиль (в т.ч. конкретная модель), крупное путешествие и похожие разовые цели → /other
— Явно пенсия / госпенсия / доп. доход к пенсии → /gosPension

Если пользователь ещё не выбрал цель и задаёт уточняющие вопросы («а в чём разница», «расскажи») без выбора — оставайся на текущей стадии: ответь тем же ключом, что в «Текущий ключ стадии» в системном сообщении.

Без пояснений, без текста — только ключ.
```

---

## Проверка

1. В админке вставь блок выше в **classifier** нужной команды, сохрани.  
2. Диалог: этап выбора цели → реплика «ну давай просто посчитаем» → в логах должен быть переход на **`/INVESTMENT`**.  
3. При `CONSTRUCTOR_AI_TRACE=1` в логах смотри `step1_classifier_llm_response` и `classifierInstructionsPreview`.
