# IDE ↔ ЛК агента (provision + SSO)

Интеграция **ide.bank-future.com** (ide-api) с **pfp-api**: один раз зарегистрировался в IDE — тот же агент в ЛК, сайт агента (`website_url`) уходит в профиль (рефералки), из IDE открывается `/cabinet` без второго логина.

| Файл | Назначение |
|------|------------|
| **[TZ.md](./TZ.md)** | Контракт: provision, sso-ticket, sso/consume, профиль, чеклист |
| **[MESSAGE.md](./MESSAGE.md)** | Короткое сообщение программисту (можно переслать как есть) |

Существующий логин агента **не ломать:** `POST /api/auth/login` (email + пароль).  
Публичная регистрация `register-agent` + OTP **остаётся** для витрины /cabinet без IDE.

**Секреты:** `PFP_IDE_SERVICE_KEY` только в `.env` на сервере, не в git.
