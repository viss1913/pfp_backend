### Страница «Портфель НПФ» (инвест) — **как на картинке** (утверждено)

**Делаем по макету**, а не полную копию HTML пенсии `59:397`.

**Включить (сверху вниз):**

1. Аватар + текст: государство следит за структурой, усреднённый портфель НПФ — **Вы / Ваши / Ваш** с заглавной.
2. Рамка фиолетовая: **круговая диаграмма** (те же доли/цвета, что в пенсии, если макет не менялся) + **легенда** (депозиты, облигации, акции, ОФЗ, муниципалки, наличные).
3. Строка **«Прогнозируемый доход — X%»** — как у пенсии: `accumulation_yield_percent` или fallback `totalYieldPercent`.
4. Два абзаца: про **≤7%** акций, риск, **19%** по ДДС у НПФ Ростех в 2025; второй — **«Если Вы начнёте пополнять … на {monthly} … накопите {сумма}»** — сумма **`projected_capital_at_end`**, **без** фразы «к моменту выхода на пенсию».
5. **Широкое фото** (ч/б, победа/небоскрёбы) — отдельный webp в `assets/reports/rostech/`, если в пенсии сейчас подставляется карточка цели — для инвеста **свой** ассет под макет (как договорим при вёрстке).
6. Абзац **про закон** (15 лет / 55 (Ж) 60 (М)) — как на макете.
7. Кнопка **«Начать»** — тот же URL ПДС, что в пенсии (`startPdsUrl`).
8. Дисклеймер мелким шрифтом — если на макете есть под кнопкой; если на картинке только футер НПФ — как в Figma.

**Не включать** (в пенсии это идёт в том же `bodyHtml` после фото — **вырезать целиком** для инвеста):

- Блок «Дополнительный ежемесячный доход = капитал × % …»
- Подпись про инфляцию к «эквиваленту … сегодня»
- Таблица **Госпенсия / дополнительный доход / итого**

**Данные:** по аналогии с пенсией (`planFacts.monthlyContribution`, проценты из `summary`, итог **`projected_capital_at_end`**).

### Данные по аналогии с пенсией (одинаковая логика, другой итог капитала)

Для страницы плана инвеста использовать **ту же схему**, что уже собрана для пенсии в `buildRostechPensionPagesHtml.js` (перед `// 59:132`):

| Назначение | Как в пенсии (не выдумывать новые пути) |
|------------|----------------------------------------|
| База полей цели | `const s = goal?.summary \|\| {}` |
| **Итоговый капитал** (тексты «накопите», «Итого капитал», масштаб третьего столбца) | В пенсии: `totalCapital` из **`projected_capital_at_retirement`**. В инвесте: **то же имя переменной по смыслу, значение из `projected_capital_at_end`**. |
| Софинансирование / вычет в тексте шагов | `pickPositive(s.cofinancing_2026, totals.cofinancing_2026)` и то же для `deduction_2026`; `totals` из **`options.overallPlan.tax_benefits.totals`** (и тот же запасной путь, что в пенсии, **не** `overall_plan.summary.tax_benefits_summary` как основной). |
| Шаги «внести / пополнять / год вычета / год софинансирования» | **`extractPensionPlanFacts(goal?.details?.monthly_schedule, { initialCapital, monthlyContribution, taxDeductionAmount, taxDeductionYear, cofinancingAmount, cofinancingYear })`** — как сейчас передаётся из `s` и `nextCalendarYear`. |
| «Собственные средства» и «Процентный доход…» на графике | **`ownFundsFallback`** = `initial + monthly * max(targetMonths, 0)`; **`ownFundsForPlan`** = `calculateOwnFundsFromSchedule(monthly_schedule, ownFundsFallback)`; **`incomeAndBenefitsForPlan`** = `max(totalCapital - ownFundsForPlan, 0)`; высоты столбцов от `maxPlanBarValue` — **как в пенсии**. |
| Выделенная строка «доходность за … год» | **`calculateAugNextYearEffectivenessPercent(monthly_schedule)`** → `highlightedYieldPercent` / `highlightedYieldYear`; fallback на **`totalYieldPercent`** — **как в пенсии**. |
| Плашка «Расчётная доходность … на весь срок» | **`accumulation_yield_percent`** из `s`, если > 0, иначе **`totalYieldPercent`** — **как строка 727** у пенсии. |
| Инфляция в других фразах страницы | **`s.inflation_rate`**, `target_months` / `term_months` — те же поля `summary`, где они уже читаются для пенсии. |

**Итог:** новые ключи JSON под инвест **не придумываем** — тот же `goal`, `goal.summary`, `goal.details.monthly_schedule`, `options.overallPlan`. Единственная принципиальная подмена цифры «весь накопленный капитал» — **`projected_capital_at_end`** вместо **`projected_capital_at_retirement`**. Остальное — копия пайплайна пенсии.
