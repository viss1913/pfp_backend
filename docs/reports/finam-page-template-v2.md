# Шаблон страницы отчета Finam (v2)

Цель: единый формат для высокой читаемости и быстрой интерпретации клиентом.

## Базовый каркас

1. **Суть**
   - 1 короткий абзац (до 2 строк), что происходит по цели/разделу.
2. **Ключевые цифры**
   - 3-5 метрик максимум: сумма, срок, взнос, дефицит/профицит, ожидаемый капитал.
3. **Интерпретация**
   - 2-3 буллета "что это значит для клиента".
4. **Действия**
   - 2-4 конкретных шага в порядке приоритета.

## Ограничения на объем контента

- Абзац: не более 2-3 строк.
- Буллет: одна мысль, одна строка (по возможности).
- На странице: не более 2 информационных акцентов одновременно.
- Детальная методология, расчеты, расширенные оговорки: только в приложении.

## Правила акцентов

- Уровень 1 (главный): сумма цели, срок, ежемесячный взнос, дефицит.
- Уровень 2 (управленческий): что будет при сохранении текущего плана.
- Уровень 3 (справочный): допущения, источники, расширенные пояснения.

## Пример микроструктуры для любой цели

- **Суть:** "До цели X при текущем темпе не хватает Y, горизонт Z месяцев."
- **Ключевые цифры:** `цель`, `текущий капитал`, `ежемесячный взнос`, `целевой капитал`.
- **Интерпретация:** 2 буллета про разрыв и риск.
- **Действия:** 3 шага: взнос, структура, контрольная дата пересмотра.

## Где использовать в текущем контуре

- Для секций с действиями: `src/reports/finam/action-plan-finam.html`.
- Для подборок стратегий: `src/reports/finam/comon-autofollow-finam.html`.
- Для риск-деклараций: `src/reports/finam/risk-declaration-preview-*.html`.
