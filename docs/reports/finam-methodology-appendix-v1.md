# Приложение: методология и расширенные пояснения (v1)

Документ для переноса второстепенных пояснений из основных страниц отчета.

## Что вынесено из основных страниц

### 1) `action-plan-finam.html`

- Расширенные продающие описания каждого шага сокращены до краткой формулы:
  - действие,
  - эффект.
- Детальные объяснения продуктов и условий оставлены для консультационного разбора.

### 2) `comon-autofollow-finam.html`

- Вводный блок сокращен до управленческой версии.
- Добавлен компактный блок критериев выбора.
- Юридико-описательный текст сокращен в пользу практической проверки перед подключением.

## Что рекомендуется хранить только в приложении

1. Развернутые методические пояснения "почему так устроен рынок".
2. Подробные сценарии и предпосылки, если они не влияют на действие клиента здесь и сейчас.
3. Длинные юридические формулировки, если они уже отражены в общем дисклеймере отчета.

## Правило для следующих версий

Если блок не помогает ответить на вопрос "что делать сейчас", он уходит в приложение.
