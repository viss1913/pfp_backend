# API Reference (Personal Financial Planning)

## Текущий домен
REST API представляет собой набор JSON-эндпоинтов, предназначенных для управления профилями клиентов и выполнения расчетов PFP (Personal Financial Planning).
Большинство эндпоинтов требуют Bearer JWT токен `Authorization: Bearer <token>`.

## Эндпоинты расчетов

### 1. Первичный расчет (First Run)
Универсальный эндпоинт для первичной оценки целей клиента и построения графиков.
- **URL**: `POST /api/clients/first-run`
- **Auth**: требуется (по JWT токену определяется Агент и Проект)
- **Body**:
  ```json
  {
      "client": {
          "total_liquid_capital": 500000,
          "avg_monthly_income": 120000,
          "birth_date": "1990-01-01",
          "sex": "M"
      },
      "goals": [
          {
              "name": "Пенсия (Пример)",
              "goal_type_id": 1,
              "risk_profile": "BALANCED"
          }
      ]
  }
  ```
- **Response**: Возвращает консолидированный финансовый план, графики капитала (по годам) и разбивку на классы активов.

### 2. Перерасчет текущих целей
Пересчет отдельной цели или пачки целей на лету (например, если пользователь потянул ползунок срока или капитала в UI).
- **URL**: `PUT /api/clients/:id/recalculate`
- **Params**: `id` — ID клиента в БД.
- **Body**: Схоже с `first-run`, но может содержать `id` или `goal_id` для корректировки конкретных целей.
- **Response**: Обновленный финансовый план.

## Эндпоинты клиентов

- `GET /api/clients` — Получить список клиентов текущего агента.
- `GET /api/clients/:id` — Получить полную карточку клиента вместе с его текущими целями.
- `POST /api/clients` — Создать нового клиента вручную.
- `PUT /api/clients/:id` — Обновить данные клиента (ФИО, телефон).

## Эндпоинты калькуляторов (Интеграционные)
- `POST /api/calculators/home-owners` — Калькулятор страхования недвижимости.
- `POST /api/calculators/pds-cofinancing` — Математика программы долгосрочных сбережений (ПДС).

> **Note**: Полный список всех методов, моделей БД и детальную OpenAPI (Swagger) спецификацию можно запустить локально открыв роут `/api-docs` после старта сервера (`node src/server.js`).
