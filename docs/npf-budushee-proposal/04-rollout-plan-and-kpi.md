# План запуска и KPI  
## PDS Light для НПФ «Будущее»

## 1. Этапы внедрения

### Этап 1. Discovery и проектирование (2-3 недели)
- финализация бизнес-требований по ПДС;
- согласование клиентских сценариев и UX;
- согласование интеграционного контура и ИБ-требований.

### Этап 2. Интеграция и настройка (4-6 недель)
- подключение источников данных НПФ;
- развёртывание on-premise компонентов;
- настройка ИИ-модели и логики рекомендаций под ПДС.

### Этап 3. Пилот (4-8 недель)
- запуск на ограниченном сегменте клиентов;
- замер продуктовых и бизнес-метрик;
- корректировка правил, текстов и UX.

### Этап 4. Масштабирование
- расширение охвата на весь целевой сегмент;
- переход в промышленную эксплуатацию;
- roadmap по развитию после лайт-версии.

## 2. KPI пилота

### Продуктовые
- конверсия из открытия сервиса в получение плана;
- конверсия из получения плана в целевое действие по ПДС;
- доля пользователей, завершивших сценарий без выхода.

### Бизнесовые
- прирост целевых действий по ПДС в цифровом канале;
- рост повторных взаимодействий с сервисом;
- вклад в удержание клиентской базы.

### Операционные
- среднее время ответа сервиса;
- стабильность интеграций;
- доля сессий без технических ошибок.

## 3. Критерии успешного пилота

- достижение согласованных порогов KPI;
- подтверждение ценности для клиента и бизнеса;
- готовность контура к безопасному масштабированию.

## 4. Следующий шаг

После согласования концепции запускается рабочая сессия с командами НПФ (бизнес, ИТ, ИБ, продукт) для фиксации:
- состава данных;
- приоритетных пользовательских сценариев;
- календарного плана пилота;
- модели управления изменениями.
