# Продуктовая концепция  
## PDS Light для НПФ «Будущее»

## 1. Продуктовая цель

Сделать для клиента ПДС простой и наглядный путь:
1) ответить на несколько вопросов;  
2) получить персональный прогноз;  
3) сразу увидеть рекомендованный план действий.

## 2. Формат клиентского опыта

### Вариант A: встроенный виджет
- размещение в ЛК или на целевой странице НПФ;
- единый UX со страницами фонда;
- быстрый старт без отдельного домена.

### Вариант B: отдельная страница
- выделенная посадочная страница под ПДС;
- удобно для маркетингового трафика и A/B-тестов;
- гибкость в контенте и промо-блоках.

## 3. Сценарий пользователя (User Flow)

1. Клиент открывает сервис ПДС-планирования.  
2. Система подгружает базовые данные клиента (при наличии доступа в ЛК).  
3. Клиент вводит/уточняет параметры: горизонт, взносы, цели, риск-профиль.  
4. ИИ формирует персональный финансовый план по ПДС-сценарию.  
5. Клиент видит результат:
   - прогноз капитала;
   - целевой сценарий и «разрыв до цели»;
   - конкретные рекомендации «что изменить, чтобы прийти к цели».  
6. Клиент переходит к целевому действию в продукте НПФ.

## 4. Что получает клиент

- Простой человеческий язык вместо сложной терминологии.
- Персональный план, а не усреднённый калькулятор.
- Наглядные сценарии «базовый / целевой / оптимальный».
- Понимание следующего шага здесь и сейчас.

## 5. Что получает бизнес НПФ

- Сильнее раскрывается ценность ПДС в цифровом канале.
- Увеличивается доля клиентов, которые доходят до целевого действия.
- Появляется управляемая аналитика по клиентским сценариям и барьерам.

## 6. Принципы лайт-версии

- Фокус только на ПДС, без перегруза дополнительными продуктами.
- Минимальное время от входа до результата.
- Максимальная объяснимость расчётов и рекомендаций.
- Подготовка к масштабированию на другие продукты после пилота.
