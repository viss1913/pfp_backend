# Коммерческое предложение  
## ИИ-финпланирование для ПДС на сайте НПФ «Будущее»

## 1. Идея

Предлагаем внедрить на сайт НПФ «Будущее» цифровой модуль персонального финансового планирования на базе ИИ.  
Решение фокусируется на продукте ПДС и помогает клиенту:
- быстро понять свой финансовый сценарий;
- увидеть прогноз будущего капитала;
- получить персональные рекомендации по шагам для достижения цели.

Формат внедрения:
- как виджет внутри текущего сайта/ЛК;
- или как отдельная брендированная страница в домене НПФ.

## 2. Что получает НПФ «Будущее»

- Рост вовлечённости клиентов в ПДС через понятную визуализацию выгоды.
- Увеличение конверсии в целевые действия (оформление/пополнение/продолжение участия).
- Снижение барьера входа: клиенту не нужно разбираться в сложных формулах.
- Современный клиентский опыт без передачи данных во внешние контуры.

## 3. Почему это безопасно и масштабируемо

Решение работает полностью в on-premise контуре НПФ:
- данные клиентов остаются внутри инфраструктуры НПФ;
- ИИ-модель развёртывается локально, без внешних API;
- контроль доступа, аудит и логирование соответствуют внутренним политикам ИБ.

## 4. Границы лайт-версии (PDS Light)

Лайт-версия сосредоточена только на сценариях ПДС:
- сбор ключевых параметров клиента;
- расчёт персонального финансового плана;
- генерация объяснимых рекомендаций;
- вывод результата в формате «что делать дальше».

Это позволяет быстро запустить ценность для клиента и постепенно расширять функционал.

## 5. Коммерческий эффект (ожидаемый)

На этапе пилота ожидается:
- рост глубины взаимодействия с продуктом ПДС;
- рост конверсии из интереса в целевое действие;
- повышение удержания клиентов через регулярный пересчёт плана.

Итог: НПФ «Будущее» получает не просто калькулятор, а цифрового помощника, который повышает ценность ПДС для клиента и усиливает продуктовую воронку.
