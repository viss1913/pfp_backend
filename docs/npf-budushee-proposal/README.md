# Предложение для НПФ «Будущее»

Этот пакет описывает запуск лайт-версии ИИ-финпланирования для продукта ПДС на сайте НПФ «Будущее».

## Состав документов

1. `01-executive-summary.md` — краткое коммерческое предложение для руководства.
2. `02-product-concept-pds-light.md` — продуктовая логика, клиентский путь и ценность.
3. `03-technical-integration-on-prem.md` — архитектура, интеграция и безопасность (on-premise).
4. `04-rollout-plan-and-kpi.md` — этапы внедрения, KPI и формат пилота.

## Цель инициативы

Сделать для клиентов НПФ «Будущее» понятный цифровой сервис, который:
- переводит сложные расчёты в персональный финансовый план;
- усиливает ценность ПДС за счёт прогноза и рекомендаций;
- работает в on-premise контуре, включая модель ИИ и данные клиентов.
