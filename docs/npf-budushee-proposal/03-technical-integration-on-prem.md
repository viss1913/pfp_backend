# Техническая интеграция и безопасность  
## On-Premise внедрение для НПФ «Будущее»

## 1. Архитектурный подход

Решение разворачивается в инфраструктуре НПФ «Будущее» по модели on-premise:
- backend-сервисы расчётов и бизнес-логики;
- локально размещённая ИИ-модель;
- интеграционный слой с системами НПФ;
- frontend-слой (виджет или отдельная страница).

Внешние облачные контуры для обработки клиентских данных не используются.

## 2. Контур данных

### Источники
- профиль клиента;
- параметры ПДС-счёта;
- транзакционная/историческая информация (по согласованному скоупу).

### Обработка
- нормализация входных данных;
- расчёт финансового сценария;
- генерация рекомендаций ИИ на основе правил и моделей.

### Выход
- персональный финансовый план;
- сценарные рекомендации;
- данные для UI и продуктовой аналитики.

## 3. Форматы интеграции

1. **API-интеграция с ЛК НПФ**  
   ЛК передаёт параметры сессии и получает ответ модуля планирования.

2. **SSO/токенная авторизация**  
   Единая сессия пользователя без повторного входа.

3. **Событийная интеграция (опционально)**  
   Передача ключевых событий в аналитический контур НПФ.

## 4. Информационная безопасность

- Разграничение прав доступа по ролям.
- Сквозное журналирование ключевых действий и изменений.
- Шифрование трафика и защита сервисных соединений.
- Развёртывание и эксплуатация по стандартам ИБ НПФ.

## 5. Нефункциональные требования (базовые)

- Масштабируемость под пиковую цифровую нагрузку.
- Отказоустойчивость критичных компонентов.
- Наблюдаемость (логи, метрики, алерты).
- Контролируемые обновления модели и бизнес-правил.

## 6. Целевой результат интеграции

НПФ «Будущее» получает безопасный on-premise модуль ИИ-финпланирования, который:
- нативно встраивается в цифровой контур фонда;
- использует внутренние данные клиента;
- выдает персональные рекомендации по ПДС в реальном времени.
