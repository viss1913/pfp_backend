# Контент-план: первые 2 недели (новичок-агент)

**Период:** 18.05.2026 (пн) — 31.05.2026 (вс)  
**Площадка по умолчанию:** Telegram-канал агента  
**Цель периода:** запустить канал, набрать доверие, 1–2 мягких лида на «разбор ситуации»  
**Ритм:** будни — 1 пост; выходные — лёгкий контент (короче, без жёсткой продажи)

---

## Переменные (подставлять перед генерацией)

| Переменная | Пример | Назначение |
|------------|--------|------------|
| `{{ИМЯ}}` | Анна | Имя в тексте, подпись |
| `{{РЕГИОН}}` | Ростовская область | Локальный контекст, примеры |
| `{{ГОРОД}}` | Ростов-на-Дону | Если отличается от региона |
| `{{ПОЛ}}` | `м` или `ж` | Склонения: консультант/консультантка, готов/готова |
| `{{СПЕЦИАЛИЗАЦИЯ}}` | пенсия, инвестиции, подушка | Фокус экспертизы |
| `{{СТАЖ}}` | 3 | Лет опыта (если нет — «веду канал открыто, делюсь практикой») |
| `{{КАНАЛ}}` | @agent_channel | CTA, ссылка на канал |
| `{{КОНТАКТ}}` | +7… / бот | Запись на разбор |
| `{{ТЕМА_НОВОСТИ}}` | ключевая ставка | Для промпта поиска новостей |

**Правило для `{{ПОЛ}}`:**

- `м` → «я финансовый консультант», «готов разобрать»
- `ж` → «я финансовая консультантка», «готова разобрать»

## Рубрикатор (14 дней)

| Рубрика | Доля | Суть |
|---------|------|------|
| Знакомство / личность | 25% | Кто ты, почему канал, ценности |
| База для новичка в SMM | 20% | Как вести канал, страхи, «с чего начать клиенту» |
| Польза / чек-лист | 25% | Мифы, 5 шагов, мини-разборы |
| Новость + вывод | ~25% | ИИ-поиск новостей → локальный вывод для `{{РЕГИОН}}` |
| Вовлечение / CTA | 5% | Опрос, вопрос, мягкая запись |

**Дисклеймер** (если тема рынок/инструменты):

> Материал носит ознакомительный характер и не является индивидуальной инвестиционной рекомендацией.

## Промпт: поиск новости (перед постами «НОВОСТЬ»)

```
Найди 3–5 актуальных новостей за последние 48–72 часа по теме: {{ТЕМА_НОВОСТИ}}.
Регион интереса аудитории: {{РЕГИОН}}, при необходимости — Россия/мир.
Исключи: сенсации без фактов, политику, clickbait.
Верни: заголовок, источник, дата, 2–3 факта, почему это важно частному инвестору в {{РЕГИОН}}.
Выбери ОДНУ новость для поста в Telegram.
```

## Промпты по дням (копировать в генератор)

### День 1 — 18.05, пн — Знакомство

```
Ты — копирайтер для финансового консультанта. Площадка: Telegram.
Имя: {{ИМЯ}}, регион: {{РЕГИОН}}, город: {{ГОРОД}}, пол: {{ПОЛ}}.
Специализация: {{СПЕЦИАЛИЗАЦИЯ}}.

Напиши первый пост канала (800–1200 знаков):
- кто я (без пафоса и без цифр доходности);
- для кого канал (жители {{РЕГИОН}}, семьи, предприниматели — выбери 1–2 сегмента);
- о чём буду писать 2 недели;
- почему можно доверять (опыт {{СТАЖ}} лет ИЛИ честно: «веду канал открыто, делюсь практикой»);
- тон: спокойный эксперт, «свой человек»;
- CTA мягкий: подписка + «напишите в комментариях, какая тема важнее».
Не обещай доходность. 3–5 коротких абзацев.
```

### День 2 — 19.05, вт — Чек-лист

```
Telegram-пост от {{ИМЯ}} ({{ПОЛ}}, {{РЕГИОН}}).
Тема: «5 вопросов к себе про деньги перед любым вложением».
Формат: нумерованный список + 1 строка пояснения к каждому пункту.
Хук в первой строке — вопрос к читателю.
В конце: «сохраните пост» + приглашение написать, какой пункт задел.
Без рекомендаций конкретных бумаг. Дисклеймер не нужен (не про рынок).
```

### День 3 — 20.05, ср — НОВОСТЬ

```
Шаг 1 — выполни промпт «Поиск новости» с {{ТЕМА_НОВОСТИ}} = «ключевая ставка, инфляция или макроэкономика РФ».

Шаг 2 — Telegram-пост от {{ИМЯ}} ({{ПОЛ}}, {{РЕГИОН}}):
- 1 строка: что случилось (факт из новости, без копипасты заголовка);
- 2–3 абзаца: что это значит для семьи/накоплений в {{РЕГИОН}};
- 1 абзац: что НЕ надо паниковать делать;
- вывод: 1 практический шаг (общий: пересмотреть подушку, сроки целей);
- источник одной строкой;
- дисклеймер про ИИР;
- CTA: «если хотите разобрать под вашу ситуацию — {{КОНТАКТ}}».
```

### День 4 — 21.05, чт — Миф

```
Пост для Telegram. {{ИМЯ}}, {{ПОЛ}}, консультант в {{РЕГИОН}}.
Миф: «Накоплю на пенсию/цель потом, сейчас рано».
Структура: миф → почему так думают → 2 аргумента почему «потом» дороже → мягкий вывод без запугивания.
Длина: 600–900 знаков. Хук — провокационный вопрос.
```

### День 5 — 22.05, пт — За кулисами

```
Пост «как проходит первая встреча с клиентом» от {{ИМЯ}} ({{ПОЛ}}, {{РЕГИОН}}).
Опиши 4 этапа: знакомство → цели → текущая картина → следующий шаг.
Без персональных данных клиентов.
Упомяни, что используешь финансовое планирование / PFP (без технического жаргона).
CTA: «если хотите такой же разбор — напишите "разбор" в {{КАНАЛ}}».
```

### День 6 — 23.05, сб — Опрос

```
Короткий пост-опрос для выходного (400–600 знаков).
{{ИМЯ}}, {{РЕГИОН}}. Вопрос: что сейчас волнует больше — пенсия, подушка, инвестиции, налоги?
2–3 предложения контекста + просьба проголосовать/написать цифру в комментариях.
Тон лёгкий.
```

### День 7 — 24.05, вс — Сторис (сценарий)

```
Сценарий цепочки сторис (3–5 кадров) для {{ИМЯ}} ({{ПОЛ}}), {{ГОРОД}}.
Тема: «воскресенье консультанта» — утро, дорога/кофе, 1 мысль недели, вопрос подписчикам.
Без продажи. Последний кадр: «что было полезного на этой неделе?»
Текст на каждый кадр — до 2 строк.
```

### День 8 — 25.05, пн — 3 цели

```
Пост-карусель (текстом: «слайд 1…5») от {{ИМЯ}} ({{ПОЛ}}, {{РЕГИОН}}).
Тема: три финансовые цели — подушка безопасности, пенсия, сохранение и рост капитала.
На каждую цель: зачем, типичная ошибка в {{РЕГИОН}}, один вопрос для самопроверки.
Финал: «с чего начать, если всё сразу» — приоритет подушки.
```

### День 9 — 26.05, вт — НОВОСТЬ (рынок)

```
Автор: {{ИМЯ}}, {{ПОЛ}}. Вывод: план снимает тревогу.
CTA: «хотите такую же схему — {{КОНТАКТ}}».
```

```
3 совета + личная фраза «я тоже…».
```

### День 12 — 29.05, пт — НОВОСТЬ (налоги)

```
{{ТЕМА_НОВОСТИ}} = «налоги, льготы, ИИС, НДФЛ — только если есть свежая новость».
Если новостей нет — замени на evergreen: «5 мифов про ИИС» (без ИИР-дисклеймера, если без конкретных бумаг).
{{ИМЯ}}, {{ПОЛ}}, {{РЕГИОН}}. Практический вывод для резидента {{РЕГИОН}}.
```

```
Пост 500–700 знаков. {{ИМЯ}} ({{ПОЛ}}, {{РЕГИОН}}).

Кому подходит / кому нет. Как записаться: {{КОНТАКТ}}.
Без давления. Упомяни, что мест ограничено (например, 5 на неделю) — честно.
```
