# SMM: ручной процесс

Ведём канал **вручную** в этом репозитории: согласовали пост с агентом → сохранили в историю → публикуете в Telegram сами.

Внешний SMM-сервис (`src/services/smmService.js`) — только синк профиля агента; **история постов здесь**.

## Файлы

| Файл | Назначение |
|------|------------|
| [channel-history.md](channel-history.md) | Согласованные и опубликованные посты (источник правды) |
| [content-plan.md](content-plan.md) | Очередь тем на 1–2 недели вперёд |
| [archive/](archive/) | Старые черновики |

Несколько каналов (позже): `docs/smm/agents/<slug>/channel-history.md`.

## Как работать с агентом

Вызови `@smm-specialist` или попроси «следующий пост для канала».

1. Агент читает `channel-history.md` и `content-plan.md`.
2. Показывает 2–3 последних поста и **один** черновик следующего (текст + картинка да/нет + промпт картинки).
3. Ты правишь / говоришь **«ок»** / **«сохраняй»**.
4. Агент добавляет строку в `channel-history.md` и отмечает тему в `content-plan.md`.

**В файл не пишем**, пока ты явно не согласовал.

## Переменные (шапка channel-history.md)

| Переменная | Пример |
|------------|--------|
| `{{ИМЯ}}` | Анна |
| `{{РЕГИОН}}` | Ростовская область |
| `{{ГОРОД}}` | Ростов-на-Дону |
| `{{ПОЛ}}` | `м` / `ж` |
| `{{КАНАЛ}}` | @channel |
| `{{КОНТАКТ}}` | бот / телефон |

## Тип поста

| Тип | Когда |
|-----|--------|
| `ИИ` | Текст сгенерирован или существенно доработан с ИИ |
| `авторский` | Текст написан автором канала |

## Визуал

| Визуал | Когда |
|--------|--------|
| `промпт` | Картинка по текстовому промпту (ИИ или дизайн) |
| `график` | Скрин графика/данных **отдельно** от промпта — свой файл в `assets/` |
| `—` | Без картинки |

## Статусы в истории

| Статус | Когда |
|--------|--------|
| `согласован` | Записали после твоего «ок», ещё не выложили |
| `опубликован` | Пост в канале (скажи агенту или поправь вручную) |

Дата/время в таблице — плановые до публикации; после выкладки можно поправить на фактические.

## Новости

Если в очереди тип `новость` — сначала ИИ-поиск новостей по теме и `{{РЕГИОН}}`, потом пост по факту. На рынок/инструменты — дисклеймер про ИИР.

## Комплаенс

Без цифр доходности и гарантий. Инвестиционные темы — пометка, что материал не является индивидуальной инвестиционной рекомендацией.
