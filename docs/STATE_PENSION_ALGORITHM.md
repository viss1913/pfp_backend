# Алгоритм расчёта государственной пенсии

> Исходный код: `src/services/calculators/PensionCalculator.js` → метод `calculateStatePension()`

---

## Общая формула

```
Госпенсия = ИПК_итого × Стоимость_балла + Фиксированная_выплата
```

---

## Пошаговый алгоритм

### Шаг 1. Определение возраста, стажа и года выхода на пенсию

**Входные данные:** `birth_date`, `gender` (пол клиента)

| Параметр | Формула |
|---|---|
| Возраст | `текущий_год − год_рождения` |
| Стаж (лет) | `max(возраст − 18, 0)` — допущение: работа с 18 лет |
| Пенсионный возраст | Мужчины: **65**, Женщины: **60** |
| Год выхода на пенсию | `год_рождения + пенсионный_возраст` |
| Лет до пенсии | `max(год_выхода − текущий_год, 0)` |

---

### Шаг 2. Приведение дохода к GROSS (до вычета НДФЛ)

**Входные данные:** `avg_monthly_income` (средний месячный доход клиента)

Доход клиента может приходить как **NET** (на руки, после НДФЛ). Для расчёта ИПК по официальной формуле нужен **GROSS** — доход до вычета НДФЛ.

Если доход указан как NET:

```
Годовой_доход_NET = avg_monthly_income × 12
Годовой_НДФЛ = calculateNdfl(Годовой_доход_NET)   // через TaxService, прогрессивная шкала
Годовой_доход_GROSS = Годовой_доход_NET + Годовой_НДФЛ
```

Если доход уже GROSS — используем как есть:

```
Годовой_доход_GROSS = avg_monthly_income × 12
```

> **Почему GROSS?** Страховые взносы в ПФР начисляются работодателем на полную зарплату до вычета НДФЛ. Именно эта сумма участвует в формуле ИПК.

---

### Шаг 3. Расчёт ИПК за текущий год

**Официальная формула ПФР:**

```
ИПК_за_год = (СВгод / НСВгод) × 10
```

Где:
- `СВгод` = страховые взносы на формирование ИПК (16.02% от зарплаты)
- `НСВгод` = нормативные страховые взносы (16.02% от предельной базы)

Процент **16.02% сокращается**, и формула упрощается до:

```
ИПК_за_год = min(10, (Годовой_доход_GROSS / pension_max_salary_limit) × 10)
```

> Максимум **10 баллов** в год (ограничение по закону).
>
> Константа `pension_pfr_contribution_rate_part1` (22%) в расчёте ИПК **не нужна** — она сокращается. Предельная база `pension_max_salary_limit` — единственный параметр.

---

### Шаг 4. Оценка накопленного ИПК (за прошлые годы)

Два варианта:

#### Вариант А: клиент указал `ipk_current` (например, с Госуслуг)

```
ИПК_прошлое = ipk_current
```

#### Вариант Б: клиент НЕ указал ИПК

```
ИПК_прошлое = (ИПК_за_год × pension_ipk_past_coef) × Стаж
```

> Коэффициент `pension_ipk_past_coef` = **0.6** — допущение: в прошлом зарплата была ~60% от текущей.

---

### Шаг 5. Прогноз будущего ИПК

```
ИПК_будущий = ИПК_за_год × Лет_до_пенсии
```

> Допущение: доход клиента в реальном выражении не меняется.

---

### Шаг 6. Итоговый прогнозный ИПК

```
ИПК_итого = ИПК_прошлое + ИПК_будущий
```

---

### Шаг 7. Индексация параметров пенсии до года выхода

Стоимость балла и фиксированная выплата индексируются на инфляцию:

```
Стоимость_балла_будущая = pension_point_cost × (1 + inflation_rate / 100) ^ Лет_до_пенсии

Фикс_выплата_будущая = pension_fixed_payment × (1 + inflation_rate / 100) ^ Лет_до_пенсии
```

---

### Шаг 8. Итоговая прогнозная госпенсия

**В ценах года выхода на пенсию (номинальная):**

```
Госпенсия_будущая = ИПК_итого × Стоимость_балла_будущая + Фикс_выплата_будущая
```

**В сегодняшних ценах (реальная, дисконтированная):**

```
Госпенсия_сегодня = Госпенсия_будущая / (1 + inflation_rate / 100) ^ Лет_до_пенсии
```

## Константы (таблица `system_settings`)

| Ключ | Значение по умолчанию | Описание |
|---|---|---|
| `pension_point_cost` | 145.69 руб. | Стоимость 1 пенсионного балла |
| `pension_fixed_payment` | 8 907 руб. | Фиксированная выплата к страховой пенсии |
| `pension_max_salary_limit` | 2 759 000 руб. | Предельная величина базы для начисления взносов |
| `pension_ipk_past_coef` | 0.6 | Коэффициент оценки ИПК за прошлые годы (60%) |
| `inflation_rate` | 4.0% | Годовая инфляция для индексации |

> `pension_pfr_contribution_rate_part1` (22%) — в расчёте ИПК **не используется**, т.к. сокращается в формуле. Остаётся в системе для других целей.

## Возвращаемые данные

Метод `calculateStatePension()` возвращает объект:

| Поле | Описание |
|---|---|
| `ipk_total` | Итоговый прогнозный ИПК |
| `ipk_current` | ИПК за прошлые годы |
| `ipk_forecast` | ИПК за будущие годы |
| `point_cost_today` | Стоимость балла сегодня |
| `point_cost_future` | Стоимость балла на момент выхода на пенсию |
| `fixed_payment_today` | Фиксированная выплата сегодня |
| `fixed_payment_future` | Фиксированная выплата на момент выхода |
| `state_pension_monthly_future` | Пенсия в ценах года выхода (руб./мес.) |
| `state_pension_monthly_current` | Пенсия в сегодняшних ценах (руб./мес.) |
| `retirement_age` | Возраст выхода на пенсию |
| `retirement_year` | Год выхода на пенсию |
| `years_to_pension` | Лет до пенсии |
| `years_of_work` | Оценённый стаж работы |
| `age` | Текущий возраст |

## Пример расчёта

**Клиент:** мужчина, 1990 г.р., доход на руки (NET) 150 000 руб./мес., ИПК не указан

```
Возраст = 2026 − 1990 = 36
Стаж = 36 − 18 = 18 лет
Пенсионный возраст = 65
Год выхода = 1990 + 65 = 2055
Лет до пенсии = 2055 − 2026 = 29

--- Приведение к GROSS ---
Годовой NET = 150 000 × 12 = 1 800 000
НДФЛ (прогрессивная шкала) ≈ 234 000
Годовой GROSS = 1 800 000 + 234 000 = 2 034 000

--- Расчёт ИПК ---
ИПК за год = min(10, (2 034 000 / 2 759 000) × 10) = 7.37

ИПК прошлое = 7.37 × 0.6 × 18 = 79.60
ИПК будущее = 7.37 × 29 = 213.73
ИПК итого = 79.60 + 213.73 = 293.33

--- Индексация ---
Стоимость балла будущая = 145.69 × 1.04^29 = 455.15
Фикс выплата будущая = 8 907 × 1.04^29 = 27 826.24

--- Госпенсия ---
Госпенсия будущая = 293.33 × 455.15 + 27 826.24 = 161 319.49 руб./мес.
Госпенсия сегодня = 161 319.49 / 1.04^29 = 51 688.22 руб./мес.
```

## Схема потока данных

```
Входные данные клиента
    │
    ├── birth_date, gender
    │       → возраст, стаж, год выхода, лет до пенсии
    │
    ├── avg_monthly_income (NET)
    │       → GROSS = NET + НДФЛ (через TaxService)
    │           → ИПК_за_год = min(10, (GROSS_годовой / Предельная_база) × 10)
    │
    └── ipk_current (опционально, с Госуслуг)
            → ИПК за прошлые годы
                │
                ├── ИПК будущий (= ИПК_год × лет_до_пенсии)
                │
                └── ИПК итого = прошлое + будущее
                        │
                        ├── × Стоимость балла (индексированная)
                        ├── + Фикс. выплата (индексированная)
                        │
                        └── = ГОСПЕНСИЯ (номинальная / реальная)
```

## Допущения и ограничения

1. Начало трудовой деятельности — **18 лет** (фиксированное допущение)
2. Доход в реальном выражении **не меняется** до выхода на пенсию
3. Если ИПК не указан, прошлый доход оценивается как **60%** от текущего
4. Индексация пенсионных параметров идёт строго по ставке **инфляции**
5. Максимум **10 баллов** ИПК в год (ограничение по закону)
6. Не учитываются: льготный стаж, досрочная пенсия, северные надбавки и прочие специальные условия
7. Доход клиента (`avg_monthly_income`) предполагается **NET** (на руки) — перед расчётом приводится к **GROSS**
