Family Office в ЛК «Правкард Забота»

Встраивание FO в личный кабинет платформы «Забота». Правкард показывает сервис сотрудникам компаний-клиентов (много работодателей — большой охват) с переходами на продукты экосистемы Сбер.

BankFuture PFP · Co-brand Правкард — на согласовании · 20 мая 2026 г.

Кратко

  • Канал: HR/бенефиты — ЛК Правкард Забота; FO внутри или рядом с привычным UX сотрудника.
  • Охват: сотрудники множества работодателей — клиентов Правкарда; одна интеграция → массовый B2B2C.
  • Для Сбера: корпоративная аудитория без собственного HR-ЛК; те же продукты и дисклеймеры, что в B2C.
  • Интеграция с ЛК: deep link / iframe / SSO — ТЗ с Правкард, в репозитории PFP не реализовано.
  • SberID: дополняет SSO работодателя (финданные), не заменяет его фаза 2

Ценность для Сбера

  • Выход на занятых сотрудников в точке, где они уже получают льготы и сервисы от работодателя.
  • Финплан «под ключ» с CTA на НПФ, страхование, УК, брокер — без отдельной рекламной кампании на каждого HR.
  • Единый согласованный отчёт и риск-декларация для всех работодателей канала.
  • Атрибуция канала Правкард (и при необходимости работодателя) — через согласованный agent_id_param.

Что уже готово у BankFuture

  • Движок FO, тенант SBER (29), отчёт v2, витрина, реферальный трекинг (после параметров от Сбера).
  • B2C-демо как референс UX для согласования с Правкард и Сбером.
  • Не готово: встраивание в ЛК Правкард — требует отдельного ТЗ (см. ниже).

Сценарий (сотрудник)

  1. Сотрудник входит в ЛК Правкард Забота (льготы, сервисы HR).
  2. Раздел «Финансовое планирование / Family Office» — встроенный виджет или переход с SSO.
  3. Опционально: «Войти через Сбер ID» для подтягивания доходов и расходов (фаза 2).
  4. Цели → расчёт → PDF-отчёт с витриной Сбера.
  5. CTA на продукты Сбера с атрибуцией канала (и/или работодателя — модель на пилоте).
[Работодатели] → сотрудники → [ЛК Забота] → embed/SSO → PFP FO → отчёт → CTA → Сбер

Интеграции

MVP сейчас

Реферальные CTA; ID канала в partner_agent_id или суб-параметр по работодателю — согласовать с Сбером.

Два входа важно

  • SSO Правкард — идентификация сотрудника в ЛК работодателя.
  • SberID — согласованный доступ к финансовым агрегатам для автозаполнения плана (отдельный consent).

ПДн

Оператор ПДн сотрудника: BankFuture / Правкард / работодатель — TBD в тройном договоре. Минимизация данных, согласие работодателя на сервис.

ИИ / GigaChat

Рекомендуем с ключами в изолированном контуре. Согласовать с ИБ Правкард и политиками работодателей (некоторые запрещают LLM для данных сотрудников).

ИБ и размещение

  • VPN / private API между контурами при iframe/SSO.
  • Журналы доступа; запрет утечки сырых выписок SberID в логи.
  • РФ-резиденция данных пилота.
