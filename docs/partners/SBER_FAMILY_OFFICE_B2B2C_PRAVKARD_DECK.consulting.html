Технический стек и безопасность данных

Стек

  • Backend: JavaScript (Node.js 20 LTS), Express
  • БД: MySQL (Knex migrations)
  • Отчёты: HTML-шаблоны + Puppeteer → PDF
  • Файлы: S3-совместимое хранилище
  • API: HTTPS REST, OpenAPI
  • Фон: node-cron; без Kafka на MVP

Безопасность

  • JWT, bcrypt, helmet, CORS, валидация
  • Изоляция по tenant (projectId 29)
  • TLS; секреты в env / Lockbox
  • Журналы без избыточных ПДн
  • Данные пилота — РФ
  • Шифрование дисков — средствами хостинга
