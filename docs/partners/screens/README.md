# Скрины для слайда «О сервисе»

Положите сюда PNG или WebP и раскомментируйте `<img>` в HTML-деках:

| Файл | Слайд |
|------|--------|
| `crm.png` | CRM и клиенты |
| `planner.png` | Финансовое планирование |
| `report.png` | Отчёт PDF |

Пример в `SBER_FAMILY_OFFICE_*_DECK.consulting.html`:

```html
<img src="screens/crm.png" alt="CRM" />
```

вместо блока-плейсхолдера в `.feature-card__shot`.
