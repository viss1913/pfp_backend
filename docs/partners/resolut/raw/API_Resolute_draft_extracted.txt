Понятие JSD -схемы Любая операция в сервисе имеет схему, описывающую требования к JSON - объект у data запроса. JSD - схема это JSON -структура, описывающая требования к узлам валидируемого объекта. JSD -схема имеет сходную с валидируемым объектом иерархию узлов, и два типа параметров в каждом узле: технические и структурные. Технические параметры начинаются с символа «$» и описывают требования к данным узла. Более подробное описание конструкций JSD -схем RI : Аутентификация Все операции, осуществляемые сервисом, кроме операции авторизации, требуют передачи ключа- токена , который можно получить с помощью операции авторизации ( authorize ) . Операция принимает логин/пароль пользователя, проверяет их валидность – пользователь должен быть зарегистрирован с этими параметрами в системе Резолют , – и возвращает постоянный ключ- токен , привязанный к пользователю.
