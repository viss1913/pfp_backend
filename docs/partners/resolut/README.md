# Resolut docs map

Все материалы по AV Inform / Resolut держим здесь, внутри `docs/partners/resolut/`.

## Структура

- `raw/` — оригиналы от партнера: `docx`, `pdf`, выгрузки, черновые extracts.
- `openapi/` — исходные OpenAPI/YAML-спеки партнера по версиям.
- `notes/` — наши рабочие заметки, архитектура, требования, результаты интеграционных проверок.
- `plans/` — внутренние планы и проверки scope/guardrails по Resolut.
