# Инструкция для ИИ: Finam Report v2

Этот файл — **правила для агента**, который правит HTML/PDF отчёт Финам **версии 2**.  
Пиши по-русски, думай как консультант, а не как «перекрась div».

Ветка git: **`report-finam`**. Базовая ветка бэкенда: **`finam`**.  
Прод включается **только после ревью человека** и merge в `finam`.

---

## 1. Что такое Finam v2 одной фразой

**Finam Report v2** — новый финплан-отчёт для проекта Финам (projectId **14**): спокойный consulting-стиль, много воздуха, модульные листы A4.  
Это **отдельный продукт** от старого отчёта v1 с клеткой и плотными goal-страницами.

| | v1 (не трогай под задачами v2) | v2 (работаешь здесь) |
|---|---|---|
| Папка | `src/reports/finam/` | `src/reports/finam_v2/` |
| Включение | по умолчанию | `system_settings.report_finam = 2` или env `FINAM_REPORT_VERSION=2` |
| Стиль | клетка, плотно | navy/blue/серый, карточки, serif-заголовки |

**Главное правило:** правка v2 **не должна** менять внешний вид v1 у клиентов без явного переключателя версии.

## 4. Как собирается отчёт у реального клиента

Отчёт — **не один фиксированный PDF**. Composer смотрит на данные и **добавляет только нужные страницы**:

1. Есть FIN_RESERVE → страница резерва  
2. Есть LIFE → life или life-subscription (по projectId)  
3. Есть PENSION → пенсия (до 3 листов)  
4. Есть пассивный доход → 2 листа без госпенсии  
5. Есть OTHER → крупная цель с картинкой по подтипу  
6. Есть накопительные цели с портфелем → итоговый портфель  
7. Нет данных → **не показывать** пустые карточки и заглушки  

**Цифры, таблицы, графики** — только из расчётов бэкенда.  
**ИИ-тексты** — narrative (вывод, риск, пояснение), не выдуманные суммы.

## 5. Правила вёрстки (по-человечески)

### Лист A4

- Шаблон: `.finam-v2-page` = **595×842 px**, `overflow: hidden`, без скролла внутри листа.
- Не влезает — **второй лист** (`article.finam-v2-page`), а не микрошрифт.
- Многостраничность **только** через несколько `article`, не iframe и не скролл.

### PDF

- Physical page для Puppeteer: **794×1123 px** (A4), внутри scale шаблона `1.333…` в loader.
- **Не** чинить поля через `FINAM_REPORT_V2_PDF_SCALE` / Puppeteer scale — это ломает v2.
- **Не** применять v1 `injectReportPdfPageFillA4` и DejaVu override к v2.

### Шрифты и классы

- Тело: **Source Sans 3**, крупные заголовки: **Source Serif 4**.
- Классы только с префиксом **`finam-v2-`**. Не смешивать с v1 (`.page`, `.speech`, `.goal-card`).

### Минимальные кегли

| Элемент | Не меньше |
|---------|-----------|
| Обычный текст | 9px |
| Таблицы, подписи | 8px |
| Футер | 8px (редко 7.5px) |
| Ниже 7px | **запрещено** |

### Цвета

- Navy / blue / soft-gray. Зелёный — только мягкий для positive-блоков.
- Карточки: белый фон, `border: 1px solid #e2e8f0`, радиус 8–12px.

### Goal-картинки

Брать из `src/reports/finam_v2/assets/` (копии из `assets/reports/goal-cards/`).  
В production пути должны инлайниться в HTML — относительные пути сами не переживут PDF.

## 6. Ограничения — что нельзя

1. **Не править** `src/reports/finam/**` «заодно под v2».
2. **Не включать** v2 по умолчанию для всех — только флаг project/env.
3. **Не трогать** Ростех (`projectId 22`) и чужие тенанты без явной задачи.
4. **Не форкать** `page-*-v2.html` под Сбер/АТБ — только branding-модули.
5. **Не хардкодить** проценты в pie/donut отдельно от данных — сумма = 100%.
6. **Не писать** «ИИ показывает» в клиентском тексте — нормальный narrative.
7. **Не сжимать** текст до нечитаемого кегля ради одного листа.
8. **Не выкатывать** на прод без проверки финального HTML-пакета и PDF.

## 8. Как проверять (обязательно перед merge)

Задача **не сделана**, пока не пройдена цепочка:

1. **Локально:**  
   ```bash
   cd src/reports/finam_v2
   python -m http.server 8766 --bind 127.0.0.1
   ```  
   Открыть `http://127.0.0.1:8766/preview-merged.html` и изменённый файл.

2. **Переполнение:** у каждого `article.finam-v2-page` — `scrollHeight <= 842`.

3. **Production HTML:**  
   `GET /api/pfp/reports/:clientId/html` — финальный пакет, не сырой шаблон.

4. **PDF** для того же клиента — без пустых страниц и жирных полей.

5. **Тесты:**  
   ```bash
   npm test -- test/finamV2LifeSubscriptionPage.test.js test/finamV2SaveGrowPage.test.js test/finamReportV2TailDynamics.test.js
   ```

Скриншоты: `node scripts/finam_v2_preview_screenshots.js` (сервер на 8766).
