Интеграция AB Inforce

Описание сущностей и функционала административной панели

В данном документе описаны основные сущности системы Antigravity PFP, их структура (названия переменных) и ключевые задачи административной панели, необходимые для начала интеграции с бэкендом.

📋 Основные сущности

1. Финансовые продукты (PFP Products)

Используются для формирования инвестиционных портфелей и расчетов доходности.

Переменные продукта:
  • id — Уникальный идентификатор.
  • name — Название продукта.
  • product_type — Код типа (PDS, IIS, ISZH и т.д.).
  • currency — Валюта (RUB, USD).
  • min_term_months / max_term_months — Диапазон сроков.
  • min_amount / max_amount — Диапазон сумм.
  • yields — Массив линий доходности (yield_percent, term_from_months, amount_from).

2. Портфели (Portfolios)

Готовые стратегии распределения капитала.

Переменные портфеля:
  • id — Уникальный идентификатор.
  • name — Название стратегии.
  • currency — Валюта.
  • riskProfiles — Массив риск-профилей (CONSERVATIVE, BALANCED, AGGRESSIVE).
  • instruments — Состав (product_id, share_percent, bucket_type).

3. Агенты (Agents)

Финансовые консультанты, работающие в системе.

Переменные агента:
  • id / uuid — Идентификаторы.
  • first_name, last_name, middle_name — ФИО.
  • email, phone — Контакты.
  • telegram_bot — Ссылка на персонального бота.
  • is_active — Статус активности.

4. Клиенты (Clients)

Лица, для которых составляется финансовый план.

Переменные клиента:
  • id — Уникальный идентификатор.
  • fio / name — ФИО или имя клиента.
  • birth_date — Дата рождения (важна для расчета пенсии и НСЖ).
  • sex — Пол клиента.
  • avg_monthly_income — Среднемесячный доход.
  • total_liquid_capital — Общий объем ликвидного капитала (Бассейн).
  • assets — Текущие активы (депозиты, недвижимость).

5. Цели (Goals)

Конкретные финансовые задачи клиента (Пенсия, Покупка, Накопления).

Переменные цели:
  • goal_type_id — ID типа цели (1: Пенсия, 2: Покупка, 5: НСЖ).
  • name — Название цели.
  • target_amount — Целевая сумма (RUB).
  • term_months — Срок достижения в месяцах.
  • risk_profile — Риск-профиль (BALANCED и др.).
  • initial_capital — Стартовый капитал.
  • monthly_replenishment — Планируемое пополнение.
  • priority — Приоритет (1 — высший).

6. ИИ Ассистенты и Конструктор

Настройка логики общения чат-ботов.

Переменные ассистента:
  • name — Название.
  • model — Модель (LLM).
  • context_template — Системный промпт.

Переменные конструктора:
  • command — Команда/стадия.
  • classifier — Критерии перехода.
  • response — Текст ответа.

7. Страхование (Home Owners)

Параметры страховых продуктов для недвижимости.

Переменные продукта:
  • rate_constructive, rate_finish, rate_property, rate_civil — Базовые ставки по рискам.

Переменные тарифа:
  • parameter_name — Имя (wall_material).
  • parameter_value — Значение (wood).
  • coefficient — Множитель.

🛠 Функционал админки

Управление каталогом Создание и редактирование банковских и инвестиционных продуктов, настройка сеток доходности.
Моделирование портфелей Сборка портфелей из продуктов, расчет долей для разных уровней риска.
Администрирование агентов Регистрация новых консультантов, мониторинг их активности и прав доступа.
Конструктор сценариев ИИ Редактирование шаблонов поведения ботов и логики переходов между этапами CJM.
Конфигурация страховки Настройка поправочных коэффициентов и справочников для страховых объектов.
Глобальные настройки Налоги (2-НДФЛ), параметры ПДС, управление API ключами нейросетей.
