# Отчёты YADRO ПДС — HTML-вёрстка

Верстка страниц PDF-отчётов по макету Figma **YADRO ПДС** (страница «Новый отчет»).
Холст 595×842px, печать A4 через `transform: scale(4/3)`. Шрифт — **Open Sans**.

Ссылка на макет: https://www.figma.com/design/pFbtmQzNgjYfFaoMPZRTqA/YADRO-ПДС

Проект содержит 6 отчётов (Pension, Capital accumulation, Flat, Passive income, Child capital,
Miscellaneous – Flight to the Moon). Только **Pension** — полный (Cover + 15 страниц). Остальные
5 отчётов имеют свои страницы 1–2 (страница 3 у всех идентична и совпадает с 4-й страницей
Pension — см. ниже), дальше переиспользуют общий «хвост» `tail-01…tail-12`.

## Остальные 5 отчётов

Для каждого: `Cover` (общий, `cover.html`) → страница 1 (интро с целью) → страница 2 (детали

отчёта — точная копия портфеля НПФ из Pension_4, без привязки к цели) → `tail-02…tail-12` как в
Pension.

Страницы 2 бывают двух типов (видно из макета):
- **Тип A** (Capital accumulation, Flat, Child capital, Miscellaneous) — «Для достижения цели
  необходимо: [шаги]» → «В 2045 году ты получишь — X ₽ / Из них: …» → график «График достижения
  цели с учетом пополнения».
- **Тип B** (Passive income) — «Что нужно сделать? 1. Открыть ПДС… 2. Дальнейшие шаги… 3. Как
  растёт капитал?» → график «График формирования пенсионного капитала с учетом пополнения»
  (структура идентична `pension-03-plan.html`).

Плейсхолдеры `{{...}}` для каждой страницы перечислены в HTML-комментарии в начале файла.

## Обнаруженные несоответствия в макете Figma (не исправлялись, скопированы дословно по ТЗ)

1. **Pension_1**: «В сегодняшних деньгах - 75 00 ₽/мес.» — вероятно, пропущен ноль (75 000).
2. **Pension_3 / Passive income_2**: «вы накопите 123 млн ₽» — не соответствует масштабу
   остальных цифр на странице (десятки/сотни тысяч рублей). Повторяется в обоих отчётах.
3. **Pension_5** («Резюме» №1): донат показывает «200 00₽», а таблица над ним — «20 000₽»
   (расхождение в 10 раз).
4. **Pension_10** («График достижения целей»): в Figma поверх части таблицы (колонка
   «Пополнение», строки 1–4) наложен декоративный серый круг, перекрывающий цифры — похоже на
   технический артефакт макета. В вёрстку не перенесён (согласовано с заказчиком в чате).
   Также значения колонок «Пополнение» (2,1–3,4 млн ₽) и «Капитал с учетом % дохода»
   (75–77 тыс. ₽) выглядят так, будто перепутаны местами по порядку величины.
5. **Pension_11** (декларация о рисках, п.1): аналогичный серый круг наложен внутри рамки риска,
   без подписи. В вёрстку не перенесён.
6. **Pension_12** (декларация о рисках, п.2): бессвязный обрывок текста «Система гарантирования
   пенсионных .» перед пунктом «2. Система гарантирования пенсионных накоплений:» — скопирован
   дословно как есть.
7. **Pension_5 / Pension_6** («Резюме» №1 и №2): содержат кнопку «Далее», типичную для экрана
   приложения, а не печатной страницы. По согласованию с заказчиком включены в вёрстку как
   обычные страницы отчёта, кнопка отрисована статично (без функциональности).
8. **Pension_8** («Альфа НПФ»): контент занимает только верхнюю ~40% страницы, остальное —
   пустое поле. Подтверждено, что это не баг, а особенность макета (аналогично странице с
   единичным блоком риска).
9. **Capital accumulation_2 / Flat_2 / Child capital_2 / Miscellaneous_2** (тип A, футер): вместо
   обычного юридического дисклеймера в макете стоит нерасшифрованный текст-заглушка
   «*- Дисклеймер» — похоже на незаполненный плейсхолдер самого дизайнера, а не финальный текст.
   Скопирован дословно; нужно уточнить у дизайнера финальную формулировку.
10. **Даты достижения целей** различаются на первый взгляд бессистемно между отчётами одного
   типа (напр. «20 марта 2045г.» у Capital accumulation_2, но «19 октября 2032г.» у Flat_2,
   Child capital_2 и Miscellaneous_2 — при этом Pension использует «2045 г.» без числа/месяца) —
   похоже на неубранные примеры данных, а не осознанный выбор дат по типу цели.

## Инцидент с Figma (важно)

При автоматизированном исследовании макета в браузере несколько раз произошёл случайный ввод
в canvas Figma вместо строки поиска (из-за того, что фокус не всегда переходил в поле поиска),
что привело к:
- созданию пустой страницы «Page 3» (дважды) — оба раза удалена через контекстное меню;
- случайной установке прозрачности 10% на объект — отменено через Cmd+Z;
- случайному перетаскиванию фрейма (Frame 332 внутри Passive income_3) — отменено через Cmd+Z.

Все правки отменены/удалены сразу после обнаружения, и финальная проверка показала, что макет
выглядит как исходно. **Тем не менее рекомендуем самостоятельно проверить историю версий файла
в Figma** (Figma → Show version history) на отчётный период, чтобы убедиться, что в макете не
осталось нежелательных изменений — на всякий случай.

## Проверка

Каждая страница проверена рендером в headless Chrome при окне 794×1123px (= 595×842 × 4/3,
как при печати) — содержимое помещается на одну страницу без обрезания футера.
Открытие в Chrome → Печать → Предпросмотр A4 должно дать тот же результат.
