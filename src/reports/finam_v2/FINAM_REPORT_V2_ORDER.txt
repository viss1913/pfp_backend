Ассеты:
  assets/cover-bg.png — фон нижней зоны обложки (дом у озера)

  goal-passive-income.webp, goal-save-grow.webp, goal-other-*.webp — локальные копии goal-cards для v2-превью

Страницы:
  1. page-cover-v2.html — обложка
  2. page-intro-v2.html — введение
  3. page-current-state-v2.html — текущее состояние (McKinsey-style; аналог prod page-3-family-finam)
  4. page-goals-v2.html — диагностика портфеля целей: Защита / Накопления / Пенсия, распределение, таблица (сейчас + инфляция), «Что важно»
  5. page-executive-summary-v2.html — управленческий вывод после диагностики целей: главный вывод, риск, рекомендуемый сценарий
  6. page-goal-fin-reserve-v2.html — цель FIN_RESERVE / Финансовый резерв, перед LIFE
  7. page-goal-life-v2.html — цель LIFE / Защита жизни, после финансового резерва
  8. page-goal-pension-v2.html — цель PENSION / Достойная пенсия, 3 листа в одном HTML, включая методику расчёта госпенсии
  9. page-goal-passive-income-v2.html — цель PASSIVE_INCOME / Пассивный доход, 2 листа в одном HTML, без госпенсии
  10. page-goal-save-grow-v2.html — цель «Сохранить и приумножить», 2 листа в одном HTML
  11. page-goal-other-v2.html — крупная покупка (квартира, дом, образование и т.д.), 2 листа в одном HTML
  12. page-portfolio-summary-v2.html — итоговый портфель: единая таблица структуры (старт/пополнение/доходность), ликвидность, риски, принципы, 2 листа в одном HTML
  13. page-tax-planning-v2.html — налоговое планирование: KPI, структура льгот, after-tax impact, compliance из overall_plan.tax_benefits, один лист
  14. page-comon-autofollow-v2.html — автоследование Comon из report.comon_showcase.items (как v1, до 6 шт.), один лист
  15. page-idu-strategies-v2.html — ДУ / стратегии Финам Фонды (каталог как v1), один лист, акцент на облигационный контур
  16. page-finam-offers-v2.html — спецпредложения Финам для новых клиентов
  17. page-roadmap-v2.html — дорожная карта 90 дней / 12 месяцев / 3 года
  18. page-inflation-v2.html — инфляция, ключевая ставка, ОФЗ и корпоративный облигационный контур из macro history
  19. page-risk-declaration-v2.html — декларация о рисках: продукты, компании, матрица Риск/Доходность, продуктовые риски, протокол контроля, 5 листов в одном HTML
  20. page-detailed-plan-v2.html — подробный план пополнений на весь горизонт расчёта; число листов зависит от длины календаря (12 строк + по 28 на продолжение)
  21. page-partner-value-v2.html — партнёрская ценность (может скрываться в клиентском PDF)
  (макет page-scenarios-v2.html в репозитории оставлен только как архив; в production PDF v2 не входит)

Интеграция в PDF/API:
  system_settings.report_finam = 1 или нет настройки — текущий Finam v1.
  system_settings.report_finam = 2 — серверный composer buildFinamReportV2HtmlPackage.js.
  Статические HTML из этого списка остаются дизайн-референсом; production composer подставляет реальные данные клиента и не должен выводить моковые цифры.
