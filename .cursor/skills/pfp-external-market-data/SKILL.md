# Внешние рыночные и макроданные (субагент / зона ответственности)

## Задача скилла

Сфокусировать работу агента на **ингесте данных из внешних официальных источников** (регулятор, биржа, статистика), их **нормализации**, **сохранении** и **расписании**, без смешения с бизнес-логикой портфелей, PDF home owners, чат-ботов и LLM.

**Сейчас в репозитории** это в основном **ЦБ РФ**, **MOEX (ISS)**, **Росстат**. При появлении новых источников того же класса (биржи, регуляторы, открытые датасеты) — **расширять этот skill** (таблица файлов, поток данных, slug-ы).

## Когда включать (триггеры)

- Правки **`macroService`**, **`rosstatService`**, **`macroScheduler`**, **`macroController`**, **`macroRoutes`**.
- Таблицы **`macro_indicators`**, миграции/сиды макропоказателей, slug-ы показателей.
- Скрипты **`scripts/parse_macro_history.js`**, **`run_macro_sync.js`**, **`test_cbr_*`**, **`test_macro.js`** и аналоги.
- Падения/таймауты внешних API, смена URL/SOAP у ЦБ, форматов MOEX ISS.
- Ручной или cron **sync** макроданных.

## Вне зоны скилла (не путать)

| Модуль | Почему не сюда |
|--------|----------------|
| `aiService`, LLM-провайдеры | Внешний API, но не рыночные данные |
| `maxBotService`, `smmService` | Мессенджеры / маркетинг |
| `pdfGenerator.js` (home owners) | Другой продукт |
| Калькуляторы пенсии/целей | Потребляют данные; меняют не источник, а формулы |
| `r2Client`, pdf-settings | Файлы и обложка отчёта |

## Источники и поток (как в коде)

| Источник | Транспорт | Сервис | Примечание |
|----------|-----------|--------|------------|
| ЦБ РФ | SOAP `DailyInfo.asmx`, частично HTML (`avgprocstav` и т.д.) | `macroService` | `CBR_SOAP_URL`, `xml2js`, `axios.post` с SOAP envelope |
| MOEX | REST ISS JSON | `macroService` | IMOEX, ОФЗ, корп. облигации (`syncImoex`, `syncOfzYields`, `syncCorpBonds`) |
| Росстат | HTTP (страницы, файлы) | `rosstatService` | Инфляция и др. |
| История (батч) | Скрипт | `scripts/parse_macro_history.js` | Долгие прогоны, XLSX/XML |

Данные обычно уходят в **`macro_indicators`** / связанные значения через методы сохранения в сервисах (см. `saveIndicatorValue` и аналоги в `macroService`).

## HTTP API приложения

- Префикс: **`/api/pfp/macro`** (`src/routes/index.js`: `pfpMiddleware`).
- **`GET /latest`**, **`GET /history/:slug`**, **`POST /sync`** (ручной полный прогон — см. `macroController.triggerSync`).

## Планировщик

- **`src/services/macroScheduler.js`** — `node-cron`: MOEX по будням после торгов, ЦБ по расписанию, Росстат и т.д.
- При добавлении новых задач — не дублировать логику парсинга вне сервисов; вызывать методы **`macroService` / `rosstatService`**.

## Правила для агента

1. **Один источник — один или чётко разделённые методы** в `macroService` / `rosstatService`; не размазывать парсинг по контроллерам.
2. **Ошибки сети**: использовать существующие паттерны логирования (напр. `logFetchError` в `macroService`) — статус, урезанное тело ответа, без утечки секретов.
3. **Таймауты** на `axios` — сохранять/увеличивать осознанно; внешние сайты ЦБ/Росстата могут быть медленными.
4. **Slug-ы показателей** — согласованы с БД и фронтом; новый показатель = миграция/сид + документирование в этом skill при необходимости.
5. **Форматы внешних API меняются** — после правок прогнать соответствующий `scripts/test_*` или ручной sync на стенде.
6. Не хардкодить **без комментария** даты «сегодня» для исторических рядов; для бэкфилла использовать скрипты с явным диапазоном.

## Скрипты (корень `scripts/`)

- `parse_macro_history.js` — глубокая история (ЦБ, MOEX, золото, инфляция и т.д.).
- `run_macro_sync.js` — запуск синка без поднятия полного UI.
- `test_cbr_soap.js`, `test_cbr_urls.js`, `test_cbr_inflation.js`, `test_macro.js` — точечная проверка источников.

## Чеклист перед PR (внешние макроданные)

- [ ] Обновлён этот skill, если добавлен **новый источник**, slug или публичный маршрут.
- [ ] Нет лишних запросов в горячем пути (кэш/расписание уже учитывают нагрузку).
- [ ] Логи при сбое позволяют отличить «наш баг» от «источник отдал 404/таймаут».
- [ ] При смене контракта API — прогнан релевантный тестовый скрипт.

См. также комментарии в шапке **`macroService.js`** (перечисление источников).
