# Платформа Antigravity PFP: Общий обзор

## 🌟 Видение
Antigravity PFP — это экосистема персонального финансового планирования (ПФП) нового поколения. Она призвана объединить сложную финансовую математику с интуитивно понятными инструментами консультирования, усиленными современным искусственным интеллектом.

## 🏗 Архитектура платформы
Экосистема состоит из четырех ключевых компонентов, интегрированных в единый рабочий процесс:

1.  **Ядро расчетов (The Brain)**: 
    Мощный бэкенд на Node.js, обеспечивающий сложные финансовые симуляции, включая прогнозы государственных пенсий, рост инвестиций и оптимизацию налоговых льгот (ПДС/НСЖ).
2.  **Личный кабинет агента (Интерфейс)**: 
    Профессиональное рабочее пространство для финансовых консультантов для управления клиентами, визуализации портфелей и формирования комплексных PDF-отчетов.
3.  **ИИ-советник (Интеллект)**: 
    Интегрированный движок на базе LLM (Gemini 1.5/2.0), обеспечивающий качественный анализ, рекомендации по стратегии и взаимодействие на естественном языке.
4.  **Центр управления (Admin)**: 
    Центральный хаб для управления общесистемными настройками, каталогами продуктов и правами доступа агентов.

## 🚀 Ключевые преимущества для партнеров
- **Алгоритм Smart Allocation**: Автоматически оптимизирует распределение «свободного капитала» клиента по нескольким жизненным целям.
- **Соответствие законодательству**: Встроенная логика учета региональных налоговых льгот (ПДС, вычеты) и государственных пенсионных систем.
- **Масштабируемый API**: Разработан для легкой интеграции с существующими фронтендами банков или страховых компаний.
- **Высокопроизводительная математика**: Выполняет многолетние симуляции с помесячной детализацией за миллисекунды.
