# Технологический стек и архитектура системы

## 💻 Технологический стек
Наша платформа использует модульный стек технологий с высокой степенью доступности, ориентированный на производительность и безопасность:

- **Бэкенд**: Архитектура, готовая к микросервисам, на базе **Node.js (LTS)** и **Express**. 
- **База данных**: Реляционная СУБД с конструктором запросов **Knex.js** для обеспечения целостности финансовых данных и транзакций.
- **Слой расчетов**: Специально разработанный движок симуляции на чистом JavaScript для максимальной скорости выполнения и предсказуемости.
- **Интеграция с ИИ**: Нативная интеграция с Google Gemini API для высокоуровневого семантического анализа и финансовых рассуждений.
- **Фронтенд**: Современное SPA-приложение (Single Page Application) на **React/Vite**, обеспечивающее отзывчивость интерфейса на уровне 60 FPS.

## ⚙️ Основные модули
- **Модульные калькуляторы**: Специализированные движки для Пенсии, Ренты, Инвестиций и Страхования жизни, которые могут обновляться независимо.
- **Событийная симуляция**: Моделирует денежные потоки на периоды 30-50 лет с учетом инфляции и рыночной волатильности.
- **Движок Smart Allocation**: Собственная логика, минимизирующая «финансовое бремя» для клиента при максимальном достижении целей.

## 🛡 Безопасность и надежность
- **Stateless API**: Обеспечивает легкое горизонтальное масштабирование и безопасное управление сессиями.
- **Ролевая модель доступа (RBAC)**: Гибкие разрешения для агентов, администраторов и партнеров.
- **Целостность данных**: Обеспечивается через атомарные транзакции базы данных и строгие схемы валидации входных данных (OpenAPI Specification).
