# Antigravity PFP Platform: General Overview

## 🌟 Vision
Antigravity PFP represents a next-generation **Personal Financial Planning (PFP)** ecosystem. It is designed to bridge the gap between complex financial mathematics and user-friendly advisory tools, powered by cutting-edge Artificial Intelligence.

## 🏗 Platform Architecture
The ecosystem consists of four pillar components, integrated into a seamless workflow:

1.  **Core Calculation Engine (The Brain)**: 
    A robust Node.js backend that handles complex financial simulations, including state pension forecasts, investment growth, and tax optimization (PDS/NSJ).
2.  **Agent Dashboard (The Interface)**: 
    A professional web workspace for financial advisors to manage clients, visualize portfolios, and generate comprehensive PDF reports.
3.  **AI Advisor (The Intelligence)**: 
    Integrated LLM-based engine (Gemini 1.5/2.0) that provides qualitative analysis, strategy recommendations, and natural language interaction.
4.  **Admin Command Center**: 
    A central hub for managing system-wide settings, product catalogs, and agent permissions.

## 🚀 Key Advantages for Partners
- **Smart Allocation Algorithm**: Automatically optimizes a client's "Liquid Capital" across multiple life goals.
- **Regulatory Compliance**: Integrated logic for regional tax benefits (PDS, Deductions) and state pension systems.
- **Scalable API**: Designed for easy integration with existing banking or insurance frontends.
- **High-Performance Math**: Handles multi-year simulations with monthly granularity in milliseconds.
- **On-Premise AI**: Open source AI model can be deployed within the client's perimeter.
