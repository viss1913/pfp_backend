# Прогноз Госпенсии - PDF Верстка

## Общая информация

Чистая HTML/CSS верстка для генерации PDF документа формата A4.
Без зависимостей от React, Vite, Tailwind или других библиотек.

## Размеры

- **Формат страницы:** A4 (595 × 842 px)
- **Внутренняя ширина контента:** 535 px
- **Боковые отступы:** 30 px с каждой стороны
- **Верхний отступ:** 30 px

## Структура файлов

```
export/
├── index.html          # Основной HTML файл
├── styles.css          # Все стили
├── README.md           # Этот файл
└── assets/             # Ресурсы
    ├── avatar.png      # Аватар пользователя (60×68px)
    └── card-image.png  # Изображение в карточке (120×70px)
```

## Примечания для интеграции

1. **Изображения:** Замените placeholder изображения в `assets/` на реальные фотографии пользователя
2. **SVG элементы:** Все SVG (рамка графика, логотип) встроены inline для надежности
3. **Абсолютное позиционирование:** Все блоки используют `position: absolute` для точного контроля в PDF
4. **Печать:** Включены `@media print` стили для корректной генерации PDF
5. **Без внешних зависимостей:** Никаких CDN, все локально

## Генерация PDF

Рекомендуемые инструменты:
- **Puppeteer** (Node.js)
- **wkhtmltopdf**
- **WeasyPrint** (Python)

Пример с Puppeteer:
```javascript
const puppeteer = require('puppeteer');

(async () => {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  
  await page.goto('file:///path/to/export/index.html', {
    waitUntil: 'networkidle0'
  });
  
  await page.pdf({
    path: 'pension-forecast.pdf',
    width: '595px',
    height: '842px',
    printBackground: true
  });
  
  await browser.close();
})();
```

## Тестирование

Открыть `index.html` в браузере:
- Геометрия должна быть строго 595×842 px
- Ничего не должно выходить за границы
- В режиме печати (Ctrl/Cmd + P) всё должно помещаться на одну страницу A4
