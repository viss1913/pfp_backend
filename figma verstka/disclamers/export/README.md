## Подготовка под динамическую подстановку

### Плейсхолдеры текста
Весь текст разбит на отдельные параграфы и списки для упрощения замены:
- Заголовки вынесены в отдельные элементы
- Списки структурированы через `<ul>` и `<ol>`
- Каждый пункт списка в отдельном `<li>`
- Избегайте склеивания текста в длинные абзацы

### Примеры для замены
```html
<!-- Заголовок легко заменить -->
<p class="section-title">{{SECTION_TITLE}}</p>

<!-- Текст параграфа -->
<p>{{PARAGRAPH_TEXT}}</p>

<!-- Список с динамическими элементами -->
<ul>
  {{#each LIST_ITEMS}}
  <li>{{this}}</li>
  {{/each}}
</ul>
```

## Требования к отображению

### Режим печати
- Стили оптимизированы для печати и PDF
- `@media print` обеспечивает корректное разбиение на страницы
- Каждая страница имеет `page-break-after: always`

### Совместимость геометрии
- В обычном режиме и print-режиме геометрия идентична
- Все размеры фиксированные (px)
- Контент не выходит за границы страницы (595×842px)

## Для интеграции в систему генерации PDF

Рекомендуемые инструменты:
- **Puppeteer** (Node.js)
- **wkhtmltopdf**
- **Prince XML**
- **WeasyPrint** (Python)

Пример использования Puppeteer:
```javascript
const puppeteer = require('puppeteer');

async function generatePDF(htmlFile, outputFile) {
  const browser = await puppeteer.launch();
  const page = await browser.newPage();
  await page.goto(`file://${htmlFile}`, { waitUntil: 'networkidle0' });
  await page.pdf({
    path: outputFile,
    format: 'A4',
    printBackground: true
  });
  await browser.close();
}
```
