# Важная Информация. Инфляция - PDF верстка для Ростех

## Спецификация

- **Размер страницы:** 595 × 842 px (A4, портрет)
- **Внутренняя ширина контента:** 535 px (отступы по 30px слева/справа)
- **Шрифты:** DejaVu Sans / Inter (системные fallback)
- **Формат:** Статичный HTML + CSS, без JS

## Структура

```
export/
├── index.html       # Главная страница
├── styles.css       # Стили
├── assets/          # Директория для ресурсов (пока пустая)
└── README.md        # Этот файл
```

## Технические особенности

- Все блоки позиционированы абсолютно (`position: absolute`)
- Размеры заданы в пикселях (для предсказуемости при экспорте в PDF)
- Сетка графика реализована через CSS градиенты
- Графики в SVG с путями из Figma
- Таблица с семантической разметкой `<table>`, легко подставлять данные

## Подготовка под динамику

Все текстовые значения и числа вынесены отдельными элементами:
- Проценты в таблице: отдельные `<td>`
- Даты на оси X: отдельные `<span>`
- Значения оси Y: отдельные `<span>`

Для подстановки переменных используйте селекторы по порядку или добавьте `data-*` атрибуты.

## Использование

1. Откройте `index.html` в браузере
2. Для печати/экспорта в PDF используйте встроенную функцию браузера (Ctrl+P)
3. В настройках печати выберите:
   - Размер: A4
   - Масштаб: 100%
   - Поля: Нет

## Режим печати

CSS содержит специальные `@media print` правила для корректного отображения при печати/экспорте.

## Ассеты

- **Шрифты:** используются системные (DejaVu Sans, Inter, Arial)
- **Изображения:** аватар заменен на градиентную заглушку
- **Иконки:** логотип встроен в HTML как inline SVG

## Примечания

- Верстка фиксированная, не адаптивная
- Проверена в Chrome/Firefox для экспорта в PDF
- Все размеры соответствуют макету Figma
- Геометрия идентична в обычном и print-режиме
