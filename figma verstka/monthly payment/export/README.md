# График достижения целей - PDF Layout

Плоская HTML/CSS верстка для генерации PDF (Ростех).

## Структура архива

```
export/
├── index.html       # Основной HTML файл
├── styles.css       # Все стили
├── assets/          # Ресурсы
│   └── avatar.png   # Аватар пользователя (60x68px)
└── README.md        # Эта документация
```

## Размеры страницы

- **Формат**: A4
- **Размер**: 595 x 842 px
- **Внутренний контент**: 535px (отступы по 30px слева/справа)

## Блоки сверху вниз

### 1. Заголовок (header-title)
- **Позиция**: `left: 30px, top: 30px`
- **Текст**: "График достижения целей"
- **Шрифт**: 18px, Regular
- **Класс**: `.header-title`

### 2. Информационная карточка (info-card)
- **Позиция**: `left: 30px, top: 80px`
- **Ширина**: 535px
- **Состав**:
  - Аватар (60x68px, border-radius: 8px)
  - Текстовый блок с описанием (428px)
- **Классы**: `.info-card`, `.avatar-container`, `.info-text-wrapper`, `.info-text`

### 3. Таблица данных (table-container)
- **Позиция**: `left: 30px, top: 210px`
- **Размер**: 535 x 410px
- **Фон**: #F3F3F4 с закругленными углами (SVG)
- **Заголовки**:
  - Дата (left: 50px)
  - Пополнение (left: 168.5px, центрировано)
  - Налоговый вычет (left: 249px)
  - Софинансирование (left: 375.5px, центрировано)
  - Итоговый капитал (left: 449px)
- **Данные**: 17 строк с шагом 20px (line-height)
- **Классы**: `.table-container`, `.table-header`, `.table-data`, `.data-column`, `.data-cell`

### 4. Логотип (logo-container)
- **Позиция**: `left: calc(50% - 232.5px), top: 811px`
- **Размер**: 70 x 19px
- **Класс**: `.logo-container`, `.logo`

## Список ассетов

### Обязательные файлы:
1. **avatar.png** (60x68px) - Аватар пользователя в карточке
   - Путь: `assets/avatar.png`
   - Формат: PNG
   - Размер: 60x68px
   - Используется в: `.info-card`

### SVG (встроены в HTML):
- Фон таблицы (rounded rectangle 535x410px, fill: #F3F3F4)

## Шрифты

- **Основной**: DejaVu Sans (системный)
- **Fallback**: Inter, системные sans-serif
- **Желательно**: Proxima Nova (если доступен)

## Динамические данные

Все текстовые значения и суммы представлены отдельными строками для легкой подстановки переменных:


## Использование

1. **Просмотр**: Откройте `index.html` в браузере
2. **Генерация PDF**: Используйте print-режим браузера или любой HTML-to-PDF конвертер
3. **Динамика**: Заменяйте содержимое `.data-cell` элементов на актуальные данные

## Примечания

- Все позиционирование абсолютное для точного соответствия макету
- Размеры зафиксированы для предсказуемой генерации PDF
- Используется минимум вложенности для простоты шаблонизации
- Подготовлено для серверной генерации с подстановкой переменных
